# Benchmark Results

There are no real benchmark measurements in this repository yet. The files generated by
automated tests use synthetic features and are written to temporary test directories; they
are not benchmark results.

After an authorized evaluation, raw schema-validated JSON belongs in
`results/v0.1.0/raw/`. Regenerate the CSV, Markdown, metadata, PNG, and SVG reports from that
JSON with:

```powershell
uv run vlbench report --input results/v0.1.0/raw --output results/v0.1.0
```

Raw result JSON and run manifests are git-ignored. Do not add datasets, checkpoints,
embeddings, caches, or private source files here. Publish only reports derived from genuine
completed runs and retain unsuccessful runs separately; see
[reproducibility](../docs/reproducibility.md).
